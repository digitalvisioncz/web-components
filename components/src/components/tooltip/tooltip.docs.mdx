# Tooltip

Web component for displaying informative text when users hover over, focus on, or tap an element.

```html
<script src="https://cdn.jsdelivr.net/npm/@dvdevcz/components@latest/dist/tooltip.js" type="module"></script>
```

or as an npm package:

```shell
yarn add @dvdevcz/components
```

```js
import '@dvdevcz/components/tooltip';
```

## Usage

To use the Tooltip component, you can include it in your HTML or JSX as follows:

```html
<dv-tooltip isActive="true" tooltipMode="follow_mouse">
  <div slot="tooltip">Tooltip Content</div>
</dv-tooltip>
```

```jsx
import Tooltip from '@dvdevcz/components/tooltip';

const App = () => (
  <Tooltip isActive={true} tooltipMode="follow_mouse">
    <div slot="tooltip">Tooltip Content</div>
  </Tooltip>
);
```

## Props

<Markdown>{`
| Prop         | Type                              | Default                  | Description                                                                 |
|--------------|-----------------------------------|--------------------------|-----------------------------------------------------------------------------|
| isActive     | boolean                           | false                    | Determines if the tooltip is active and visible.                            |
| tooltipMode  | TooltipPositionModeEnum           | follow_mouse             | Sets the mode for tooltip positioning. Options: click, follow_mouse, static, none. |
| position     | { x: number, y: number }          | { x: 0, y: 0 }           | Sets the static position of the tooltip when tooltipMode is static.         |
`}</Markdown>
